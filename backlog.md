# FACTA — Development Backlog (Pre-1.0.0 History)

> **Catatan (extraction ke repo publik ini):** file ini adalah log pengembangan APA ADANYA dari monorepo privat asal (`CoreAI-CPanel/src/aiquran`), sebelum kode diekstrak ke repo `StechSuite/FACTA` ini. Skema versi `1.01.Alpha.xxx` di bawah adalah skema INTERNAL repo lama — repo publik ini mulai dari baseline baru **1.0.0** (lihat [`CHANGELOG.md`](CHANGELOG.md) untuk versi selanjutnya). File ini dipertahankan apa adanya sebagai catatan sejarah/transparansi proses development, bukan backlog aktif repo ini.

Backlog dan status pengembangan FACTA (dulu "SmartQuran", `src/aiquran` — nama folder/domain live tidak diubah, lihat v1.01.Alpha.023), beserta statusnya. Aturan pengelolaan:
- Issue dikelompokkan per tanggal rilis/permintaan, **diurutkan dari yang paling baru ke yang paling lama**.
- Setiap issue dicatat dalam bentuk tabel dengan kolom **Status** (kosong/`TODO` = belum dikerjakan, `IN PROGRESS` = sedang dikerjakan, `DONE` = selesai, `BLOCKED` = menunggu input/keputusan), **Progress** (ringkasan kemajuan atau catatan blocker), dan **PIC** (Agent AI + Model yang mengerjakan, misalnya "Sonnet on Claude").
- Agent AI akan mengeksekusi backlog, apakah pengembangan fitur atau fix bugs dan melakukan auto commit dan push ke remote repository
- Issue baru ditambahkan sebagai grup tanggal baru di **atas** (paling atas = paling baru) dengan mengupdate backlog number. Misalnya 1.01.Alpha.001 menjadi 1.01.Alpha.002. Selalu update versi yang ditampilkan di halaman utama aplikasi
- Tambahkan issue baru dengan menuliskan tanggal (format `YYYY-MM-DD`) dan daftar itemnya; agent akan mengubahnya ke format tabel di atas secara otomatis.
- Issue juga bisa ditambahkan oleh Agent AI hasil dari request/prompt di agent atau hasil analisis/review/testing result. Jangan ragu bertanya!
- **Jangan taruh kredensial/secret (password, API key, dsb.) langsung di file ini** — file ini di-commit ke git dan tidak di-gitignore. Simpan secret di `deploy.secrets.json` atau `config.keys.json` (keduanya sudah di-gitignore), lalu referensikan saja lokasinya di sini.
